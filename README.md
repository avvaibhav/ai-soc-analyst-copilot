# AI-Powered SOC Analyst Copilot

An AI-assisted SOC dashboard that analyzes SIEM alerts, maps events to MITRE ATT&CK techniques, and provides security insights.

## Features

- CSV Log Upload
- Alert Statistics
- MITRE ATT&CK Mapping
- Severity Visualization
- Threat Investigation Dashboard

## Tech Stack

- Python
- Streamlit
- Pandas
